This is a web app that integrates Spotify's API to allow users to keep track of and search for new music. The app tracks and stores the user's Spotify listening history in a database, and listening history from other platforms (YouTube, Soundcloud, etc.) can be tracked using a third party browser extension called a Web Scrobbler. The Web Scrobbler employs webhooks that allow even-driven data transfer directly from a streaming platform to our database.
